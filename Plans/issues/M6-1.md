# M6-1 · Language/i18n foundation and translation workflow

Milestone: M6 · Labels: docs, ux, M6

## Description
Establish the language and translation foundation needed to support English, Hungarian, German,
Spanish, Italian, French, Vietnamese, and Chinese without creating inconsistent catalogs or
fragile UI behavior. Build on the existing zero-dependency `src/i18n` layer unless a concrete
requirement proves a dependency is necessary.

## Tasks
- Inventory every user-visible string across onboarding, tabs, wardrobe/catalog, capture, studio,
  looks, settings, permissions, errors, and sharing.
- Define the supported locale type and metadata for `en`, `hu`, `de`, `es`, `it`, `fr`, `vi`, and
  `zh`, including display names and selection order.
- Make the English catalog canonical and add a completeness check that reports missing keys and
  unexpected keys per locale.
- Define fallback, interpolation, plural/number/date formatting, and persistence behavior; keep
  locale switching free of reload crashes.
- Document the translator workflow, terminology rules, and how a future locale is added.
- Add focused tests for locale resolution, catalog coverage, fallback behavior, and placeholder
  preservation.

## Acceptance criteria
- [ ] All eight requested locales are represented in typed locale metadata and are selectable
      through the existing language flow.
- [ ] A canonical English catalog and automated per-locale coverage check exist.
- [ ] Missing translations have a deterministic, documented fallback and never render as blank UI.
- [ ] Interpolation and formatting rules are documented and tested for the strings that need them.
- [ ] Locale selection persists and switching locales does not reload-crash the app.
- [ ] A concise translation workflow is linked from the project planning documentation.

## Status: BACKLOG
