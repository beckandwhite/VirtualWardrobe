# M5-3 - [autonomous] Private GitHub Actions runner from Docker

Milestone: M5 · Labels: tooling, qa, M5

## Autonomous-subagent brief

Execute this issue autonomously. Routine infrastructure decisions are allowed. For material
security, hosting, or cost decisions, choose the lowest-risk option consistent with repository
policy, log the decision in `Plans/decision-log.md`, and continue. Finish as `DONE`, `PARTIAL`, or
`NO-GO`; do not commit or open a pull request.

## Goal
Define and, where repository permissions permit, prove a private GitHub Actions runner packaged
as a Docker-based deployment. This is an infrastructure option, not a prerequisite for the public
GitHub-hosted CI in M5-1/M5-2.

## Tasks
- Specify the supported host, Docker version, runner image, labels, resource limits, and network
  egress policy.
- Create a non-secret bootstrap/configuration procedure; never commit runner tokens.
- Provide a disposable local smoke path that confirms the runner can accept a labeled job.
- Document repository/org permissions, secret requirements, maintenance, patching, and teardown.
- If private-runner access is unavailable, record the exact blocker and leave no registered runner.

## Acceptance criteria
- [ ] A versioned Docker setup and operator documentation exist without embedded secrets.
- [ ] The runner uses least privilege, explicit labels, and a documented egress policy.
- [ ] A labeled smoke job succeeds, or the unavailable GitHub permission/hosting prerequisite is
      recorded as PARTIAL/NO-GO.
- [ ] M5-1 remains the default GitHub-hosted CI path and is not made dependent on this issue.
- [ ] The decision, security posture, and teardown procedure are logged in the main decision log.

## Dependencies
M5-1 and M5-2 are independent and remain usable without this runner. Requires an approved
private-runner host and GitHub permissions before execution.
