### Findings (see Plans/decision-log.md D8–D15)
- **D10 — expo-sqlite fails `expo export --platform web`.** SDK 57's web worker imports
   `wa-sqlite.wasm`, which Metro's production resolver won't pick up. Mitigated: all three
   automated gates pass (below). Web-production export deferred; `expo start --web` dev mode works.
- **D14 — `eslint-plugin-react` incompatible with ESLint 10.** Pinned to `eslint@~9`.
- **D13 — `tsconfig.exclude: ["tests"]`.** Keeps the app `tsc --noEmit` clean.
- **D15 — `react-hooks/set-state-in-effect` flagged on initial-load effects.** Silenced as
   known false positive, revisiting when data-loading hooks land.
