# M2-1 · Web MoveNet pose integration

Milestone: M2 · Labels: ml, M2

## Description
The "wow": pose-aware drape on web, where it's cheapest to ship and demo.

## Tasks
- Install `@tensorflow-models/pose-detection` (+ web backend) for the web build only.
- Implement `MoveNetPoseProvider implements PoseProvider` returning keypoints.
- Wire the studio to use it on web; native still uses the manual provider.
- Show a faint keypoint overlay so the auto-box is legible to the user.

## Acceptance criteria
- [ ] On web, uploading/capturing a body photo yields keypoints within a few seconds.
- [ ] Keypoints feed `computeGarmentBox` (M0-2).
- [ ] Fails back to manual if the model fails to load.
- [ ] Attaches a screenshot + one-run demo note to this issue.
