# M2-4 · Manual-overlay fallback (no ML)

Milestone: M2 · Labels: feat, ux, M2

## Description
Guarantee the studio is fully usable without any pose model — this is what native ships in MVP.

## Tasks
- When `PoseProvider` returns `null` (native in MVP), the user positions/scales the garment
    fully manually.
- A clear affordance that "auto-drape unavailable, adjusting manually".
- The composer must be identical code whether auto or manual produced the initial transform.

## Acceptance criteria
- [ ] Native (no ML) can produce a saved look end-to-end.
- [ ] No code path requires a pose model to function.
- [ ] The auto (web) and manual (native) paths share the same transform type.

## Notes
This is what de-risks M3-1: even if native ML fails, the app works.
