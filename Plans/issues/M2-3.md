# M2-3 · Save/share output to Photos

Milestone: M2 · Labels: feat, M2

## Description
Make the result useful: export the composited look and share it.

## Tasks
- `expo-image-manipulator`/`expo-sharing` to render the final composite to an image file.
- Save a `TryOn` row (bodyPhoto + item + transform + outputPath) to the store.
- "Share" via the native share sheet; "Save to Photos" option.
- A saved-looks list within the studio (minimal; full gallery is M3-2).

## Acceptance criteria
- [ ] A composite exports to a file and shares via the share sheet.
- [ ] A `TryOn` row is created and can be reopened later.
- [ ] "Save to Photos" works on a simulator build.
- [ ] Failed export is visible, not silent.

## Deps
Depends on M2-2.
