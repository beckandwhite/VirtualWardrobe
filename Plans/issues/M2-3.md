# M2-3 · Save/share output to Photos

Milestone: M2 · Labels: feat, M2

## Description
Make the result **useful and shareable** — the payoff of the try-on studio. The user finishes a
composite (M2-2), renders it to a real image file, and can then share it via the native share
sheet or save it to Photos. We also persist a `TryOn` row (bodyPhoto + item + final transform +
output image path) so the look can be reopened and re-shared later (M3-2 promotes this into a
full gallery). For MVP we keep the studio's saved-looks list **minimal** — just enough to prove
the loop; the first-class gallery is M3-2.

The composite-to-image step is the fiddly part cross-platform: web can render to a `<canvas>` and
export a blob; native needs `expo-image-manipulator` to render the layered image to a file.

## Tasks
- `src/composer/export.ts` — `exportTryOn(composition)`: flatten the body photo + garment image at
  the final transform into a single image file. Web: draw to a canvas + `toBlob`/data URL →
  `expo-file-system`. Native: `expo-image-manipulator` `Manipulator` composite/manipulate to a
  saved path.
- On export, create a `TryOn` row via the M0-3 repo: `{ bodyPhotoId, itemId, transform, outputPath,
  createdAt }` (transform reused verbatim from M2-2).
- `expo-sharing` `Sharing.shareAsync(filePath)` for the share sheet; add a "Save to Photos"
  action (native uses the save-to-library path; web degrades to a download).
- A **minimal** saved-looks list inside the studio (a short horizontal row or list of recent
  `TryOn` thumbnails) that can reopen a look into the editor.

## Acceptance criteria
- [ ] A finished composite exports to an image file and shares via the native share sheet
      (simulator) / browser share (web).
- [ ] A `TryOn` row is created with the exact final transform + output path and can be reopened.
- [ ] "Save to Photos" works on a simulator build (iOS/Android); on web it downloads the image.
- [ ] A failed export surfaces a visible error (toast/dialog), never silent.
- [ ] The minimal saved-looks list reflects new exports and can reopen one.

## Deps
Depends on M2-2.

## Out of scope
- Full saved-looks gallery, sorting, or a dedicated "Looks" screen — that is M3-2.
- Cloud upload of the output — deferred (ADR-004).
