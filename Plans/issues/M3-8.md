## Problem
`docs/dev-setup.md` §7.1 states the dev env **can't render a web UI** — `@playwright/test` is
*not installed*, so the M3-5 harness (`npm run e2e:pose`) can only skip to the manual path and
the Chromium screenshot (M3-5 AC1, M2-1's `ml` DoD) is deferred "to a browser-available machine."
That limitation has **no setup instructions anywhere**. A fresh dev (or a CI runner) has no
repeatable answer to "how do I get the browser test environment?" This item writes that doc.

This is the **documentation half** of the Playwright pair; **M3-9** is the *actual* setup on
this MacBook. They share a target but this issue produces *prose + commands*, M3-9 *executes*
them and proves the run.

## Goal
Add a precise, copy-pasteable section to `docs/dev-setup.md` (a new **§8 "Web-test environment
(Playwright)"** or extend §5/§7) that tells any dev how to install and run the Playwright web-test
environment on **macOS / Linux / Windows**, including the OS-level browser deps — so the M3-5
browser pass can actually fire instead of skipping.

The Playwright package is a repository devDependency, not an optional global tool. The browser
pass is required in CI once this work lands; the model-absent manual fallback remains valid.

## Tasks

    1. **Install:** `npm i -D @playwright/test` (respect the repo's minimal-deps stance, D21.3/
       D23.1 — note it's a *devDependency* for tests only) + `npx playwright install --with-deps
       chromium` (the `--with-deps` OS bits matter on Linux; call out macOS/Windows differences).
    2. **One-time OS browser deps** per platform: Linux needs system libs (`--with-deps` or
       `npx playwright install-deps`); macOS needs a recent Xcode CLT; Windows notes.
    3. **Point Playwright at the Expo web build.** `scripts/pose-smoke.mjs` drives
       `expo start --web`; document how the harness launches/attaches (and the `import/no-
       unresolved` carve-out in `eslint.config` for `scripts/**/*.mjs`, D22.2 — keep it).
    4. **Run:** `npm run e2e:pose` → expected PNG at `docs/screenshots/studio-<ts>.png` +
       `docs/screenshots/last-run.md`.
    5. **Verify + skip behavior:** with the model present → auto path + PNG (closes M3-5 AC1 /
       M2-1 `ml` DoD); with the model absent → manual path, exits 0 (don't regress the skippable
       contract).
    6. A "gotchas" list (browser not downloaded, headless vs headed, CI image choice).
