# M6-5 · Spanish translation completion

Milestone: M6 · Labels: docs, ux, M6

## Description
Complete the VirtualWardrobe translation catalog for the existing Spanish locale (`es`) using the
language foundation and canonical English copy established in M6-1 and M6-2. This is a user-facing
localization work item, not a new navigation or feature slice.

## Tasks
- Review and complete every supported user-visible string in Spanish, including navigation,
  onboarding, wardrobe/catalog, capture, studio, looks, settings, permissions, empty states,
  errors, and share/export actions.
- Preserve placeholders, interpolation tokens, accessibility labels, and action meaning exactly
  while correcting any unnatural or inconsistent Spanish wording.
- Review the result in the language switcher and across the core storyboard journey; fix
  truncation, awkward line breaks, and misleading translations.
- Add or update locale-specific catalog tests and document intentional terminology decisions.

## Acceptance criteria
- [ ] The `es` catalog is complete with no missing keys, fallback-only values, or untranslated
      English in supported user-facing surfaces.
- [ ] Placeholder and interpolation tokens match the canonical English catalog exactly.
- [ ] Spanish can be selected, persists across relaunch, and renders without a reload crash.
- [ ] The core journey is reviewed in Spanish, including empty and error states.
- [ ] Automated catalog checks pass and translation decisions are documented.
