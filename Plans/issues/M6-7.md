## Description
Expand the VirtualWardrobe translation catalog for the French locale (`fr`) using the language
foundation and canonical English copy established in M6-1 and M6-2. This is a user-facing
localization work item, not a new navigation or feature slice.

## Tasks
- Translate every supported user-visible string in the canonical catalog, including navigation,

- Preserve placeholders, interpolation tokens, accessibility labels, and action meaning exactly
  while allowing natural French wording and grammar.
- Review the result in the language switcher and across the core storyboard journey; fix
  truncation, awkward line breaks, and misleading translations.
- Add or update locale-specific catalog tests and document any intentional terminology decisions.

## Acceptance criteria

- [ ] The locale can be selected, persists across relaunch, and renders without a reload crash.
- [ ] The core journey is reviewed in French, including empty and error states.
- [ ] Automated catalog checks pass and translation decisions are documented.
