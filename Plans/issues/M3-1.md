# M3-1 · [spike] EAS prebuild + MediaPipe/Tasks pose for native

Milestone: M3 · Labels: spike, ml, M3

## Description
**Non-blocking spike.** Try to bring on-device pose to native behind the existing
`PoseProvider`, so web and native finally share one implementation.

## Tasks
- Create an EAS **prebuilt** dev client (Expo Go can't run custom native code).
- Integrate `@mediapipe/tasks-vision` (PoseLandmarker) or `react-native-vision-camera`
    + on-device model.
- Implement `MediaPipePoseProvider implements PoseProvider`.
- Decide **go / no-go** and write a conclusion + an ADR if it changes the plan.

## Acceptance criteria (spike success)
- [ ] A device build runs on-device pose and returns keypoints.
- [ ] Keypoints feed `computeGarmentBox` exactly like web.
- [ ] If no-go: documented reasons + the manual fallback (M2-4) remains the native path.

## Notes
The #1 risk in the whole project. Kept as a spike so it never blocks the MVP.
