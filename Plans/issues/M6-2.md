# M6-2 · English canonical catalog and copy review

Milestone: M6 · Labels: docs, ux, M6

## Description
Make English (`en`) the complete, intentional source catalog for all user-visible copy before
translating the other five locales. This includes replacing remaining inline strings and resolving
ambiguous terminology so translators have stable source text.

## Tasks
- Move remaining user-visible strings into the canonical English catalog, including accessibility
  labels, permissions, errors, empty states, and share/export actions.
- Review wording for consistent terms such as item, garment, wardrobe, look, try-on, capture, save,
  and share.
- Add descriptions or translator context where a short source string is ambiguous.
- Verify the canonical catalog against the M3-14 storyboard and the implemented app routes.
- Add tests or checks that prevent new user-facing strings from bypassing the catalog.

## Acceptance criteria
- [ ] The canonical English catalog covers every supported user-facing surface and state.
- [ ] Core terminology is consistent and documented where a translator could reasonably interpret
      it more than one way.
- [ ] Accessibility labels, permission prompts, errors, empty states, and share/export copy are
      included.
- [ ] The M3-14 core journey can be completed in English using catalog-backed strings.
- [ ] Catalog coverage and no-inline-string checks pass.
