# M0-5 · Studio route + pose→garment demo

Milestone: M0 · Labels: feat, ux, ml, M0

## Description
Wire the M0-2 pieces into a visible "wow": a `studio` route that loads a body photo, runs a
`PoseProvider` (a **sample pose** in M0, real web MoveNet in M2-1), places an auto-scaled garment
via `computeGarmentBox`, and lets the user fine-tune with a transform editor. No Reanimated yet —
the editor is a simple absolute-positioned `View` driven by state. This milestone proves the full
pipeline `pose → box → transform → composed view → save → /looks` on screen, today.

## Tasks
- `app/studio.tsx`:
    - Body photo: default to a bundled `assets/sample/body.png`; "Pick photo" via
       `expo-image-picker` (Q3).
   - Garment: from the chosen catalog/wardrobe `Item` (via `/studio?id=`), image from
    `item.imagePaths[0]`; defaults first catalog item (Q2/Q5: placeholder PNG).
   - Provider via `createPoseProvider()` → web/M0-5 returns `SAMPLE_KEYPPOINTS`
    (`SamplePoseProvider`); native → `ManualPoseProvider` (Q4).
   - `computeGarmentBox(keypoints, item.type)` → initial `Transform`; on null, start from
    `IDENTITY_TRANSFORM` + "adjusting manually".
    Render the body image full-screen with the garment image overlaid, positioned/scaled by
    `Transform` as an absolute `View` (`transform: [translateX, translateY, scale, rotate,
     opacity]`).
    - Manual editor (state-driven, no Reanimated): position (drag the overlay), scale, rotation,
    opacity, plus a **Reset** that recomputes from pose. M2-2 upgrades to Reanimated pinch/drag.
  - Save → `r.insertTryOn(bodyPhotoId, itemId, serializeTransform(t))`; then to `/looks`.
  - Deep-link in: `wardrobe.tsx` "Try on" → `/studio?id=<itemId>`; `looks.tsx` open → `/studio`.
- Pose layer additions:
   - `SAMPLE_KEYPPOINTS: Keypoint[]` — the Q6 fixture.
   - `SamplePoseProvider` — returns the fixture; `createPoseProvider()` factory in `src/pose/`.
   - Wire catalog `imagePaths` → sample asset keys; add a key→asset resolver + `.png`/`.jpg`
    module type declarations so `Image` compiles.

## Notes
Ugly-by-design: the editor is primitive so M2-2 (Reanimated pinch/drag + keypoint overlay,
M2-1) can upgrade it. The whole point is that the data flow `pose→box→transform→save→/looks`
is fully exercised today. See `Plans/decision-log.md` D16 for the grilling record.
