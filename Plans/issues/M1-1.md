# M1-1 · Camera + library capture

Milestone: M1 · Labels: feat, M1

## Description
Let users add items by photo. Capture from camera or pick from the photo library.

## Tasks
- `expo-camera` for in-app capture.
- `expo-image-picker` for library import.
- On capture/import, create an `Item` draft (untyped until M1-2).
- Auto-detect garment type by heuristics/optional model (best-effort; can be manual too).

## Acceptance criteria
- [ ] Camera and library both produce a saved image + an `Item` draft row.
- [ ] Works on web (file input) and simulator.
- [ ] Fails gracefully when camera unavailable.

## Deps
Depends on M0-3 (storage) and M0-4 (permissions).
