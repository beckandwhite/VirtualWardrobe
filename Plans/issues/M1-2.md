# M1-2 · Item CRUD + thumbnail gen

Milestone: M1 · Labels: feat, M1

## Description
Full create/read/update/delete for wardrobe items, with auto thumbnails.

## Tasks
- Create: finalize a draft from M1-1 (type, category, color, tags).
- Read/Update/Delete via the store layer from M0-3.
- `expo-image-manipulator` to generate a thumbnail + a transparent-ish "garment cutout" if
    a simple auto-trim is feasible (keep optional; manual crop acceptable).
- A detail/edit screen for an `Item`.

## Acceptance criteria
- [ ] Add / edit / delete an item persists across restart.
- [ ] Thumbnail rendered in the gallery.
- [ ] Edit updates the stored item; delete removes it + its related TryOn rows.
- [ ] No orphaned files (or acceptable GC for MVP).

## Deps
Depends on M1-1.
