## Problem
The M3-5 harness (`scripts/pose-smoke.mjs`, `npm run e2e:pose`) is built but its browser pass
is **waived in the sandbox**: `@playwright/test` is not installed and `expo-sqlite`'s
`wa-sqlite.wasm` blocks `expo export --platform web` (D10). So the studio PNG (M3-5 AC1 /
M2-1's `ml` DoD) has never actually been produced on a real browser. **This item performs the
actual setup on this MacBook** so the pass can fire — it is the *execution* half; M3-8 is the
*documentation* of the same procedure.

## Goal
On a macOS host, install `@playwright/test` + a Chromium browser and get `npm run e2e:pose` to
**actually render the Expo web build and emit a PNG** (auto path if the MoveNet model is
present, else the skippable manual path). Prove M3-5 AC1 can be met when a browser is present.

## Host rule

This workspace is Windows. Do not claim a Mac setup succeeded here; treat this issue as a future

## Tasks
1. Install the runner as a **devDependency** (keep ADR-004: runtime unaffected):
    `npm i -D @playwright/test`. Pin the version; record it.
2. Install the browser: `npx playwright install --with-deps chromium` (mac: `npx playwright
   install chromium`; `--with-deps` is a Linux/CI concern). Note the browser path Playwright
   uses.
3. Resolve the `expo export` web-block if it surfaces in a static build: D10 already established
   the app boots in `expo start --web` dev mode where Metro resolves `.wasm` at runtime — the
   M3-5 harness drives `expo start --web`, **not** `expo export`, so no production export is
   needed. Verify the harness path; log any wrinkle.
4. Run `npm run e2e:pose`. Expected: a PNG under `docs/screenshots/studio-<ts>.png` +
   `last-run.md`, exit 0. If the model is absent, it must assert the manual path and still exit 0.
5. Run the gate: `npx tsc --noEmit`, `npx eslint . --max-warnings 0`, `npm test`. All green
   (note the `scripts/**/*.mjs` `import/no-unresolved` carve-out, D22.2 — keep `eslint` green).
6. Confirm M3-8's documented commands match what actually worked; if not, flag the doc for M3-8.
