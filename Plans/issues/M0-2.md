# M0-2 · Define PoseProvider + Compositor interfaces

Milestone: M0 · Labels: feat, ml, M0

## Description
Create the platform abstraction that keeps web (ML) and native (manual) codepaths in sync
from day one, so the composer UI never branches on platform.

## Tasks
- `src/pose/PoseProvider.ts`: interface `estimate(bodyPhoto): Promise<Keypoint[] | null>`
   and a `ManualPoseProvider` that returns `null` (drives the fallback).
- Define `Keypoint` + the `computeGarmentBox(keypoints, garmentType)` pure function in
   `src/composer/`.
- `src/composer/Compositor`: manual transform type `{x,y,scale,rotation,opacity}` + an
   `exportComposition` signature (impl can stub to null for now).
- Write unit tests for `computeGarmentBox` against a few known keypoint sets.

## Acceptance criteria
- [x] Interfaces compile under `strict`.
- [x] A manual-only path works end-to-end with **no ML dependency installed**.
- [x] `computeGarmentBox` tests pass (Jest).
- [x] No platform-specific imports leak into the composer UI.

## Notes
This is the de-risking task for M2/M3. If it's clean, native ML (M3-1) drops in unchanged.

## Status: DONE (2026-09-18)

### What shipped
- `src/pose/types.ts` — `Keypoint`, `KeypointName` (17-point pose), `GarmentType`, `Transform`,
    `serializeTransform`/`deserializeTransform` + `IDENTITY_TRANSFORM`.
- `src/pose/PoseProvider.ts` — `PoseProvider` interface, `ManualPoseProvider` (returns `[]` →
    drives fallback), `safeEstimate()` (no-throw wrapper), `pickKey()` helper.
- `src/composer/autoBox.ts` — `computeGarmentBox(keypoints, type)` → deterministic
    `Transform | null` via anchor math (shoulder/hip/ankle), with `boxToTransform`.
- `tests/autoBox.test.ts` — 6 Jest cases (empty → null; top centering; shoes near ankles;
   dress taller than top; missing hips → null; transform identity fields).

### Findings
- Anchor-point model is pure and deterministic — the key de-risking goal: **native ML (M3-1)
   can drop into the same `PoseProvider` interface with zero composer changes.**
- `ManualPoseProvider` returns `[]` (empty) rather than `null`; the composer treats empty
    keypoints as "use `IDENTITY_TRANSFORM` + manual controls" (M2-4 fallback path).
