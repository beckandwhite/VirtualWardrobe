# M3-4 · [optional] Account + multi-device sync

Milestone: M3 · Labels: feat, M3, debt

## Description
**Separately scoped / optional.** Adds a real account + optional cloud sync of the wardrobe.
Not started in MVP; only when the product direction calls for it.

## Tasks
- Decide auth provider (Clerg/Auth0/Firebase) — separate decision.
- Migrate store to a sync-aware backend (WatermelonDB) — see ADR-006.
- Opt-in sync of wardrobe/looks; bodies can stay local (ADR-004) or opt into cloud.
- GDPR-consent flow for any personal data leaving the device.

## Acceptance criteria
- [ ] A user can sign in and see the same wardrobe on two devices.
- [ ] Sync is opt-in; default remains local.
- [ ] A privacy/consent step gates any upload.

## Notes
Out of MVP by design. Listed only so the path is explicit.
