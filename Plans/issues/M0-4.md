# M0-4 · Permissions onboarding flow

Milestone: M0 · Labels: ux, M0

## Description
First-run experience that replaces "auth first": grant camera + photo + storage permissions,
guest-only.

## Tasks
- Gate camera access and photo-library access with permission prompts.
- Handle **denied** gracefully (link to iOS/Android settings; don't crash).
- Persist a `hasOnboarded` flag so it only runs once.
- Minimal i18n-ready strings (structure only, no catalogs yet).

## Acceptance criteria
- [x] First launch shows the onboarding; granting all permissions unblocks the app.
- [x] Denying camera still lets the user browse the catalog.
- [x] Re-launching skips onboarding (via `has_onboarded` flag).
- [x] No crash on any permission outcome (`safeEstimate`-style guards; try/catch).

## Notes
This is the near-term "auth-ish" item; account/sync is M3-4.

## Status: DONE (2026-09-18)

### What shipped
- `app/onboarding.tsx` — first-run gate: camera permission prompt via
    `Camera.Camera.requestCameraPermissionsAsync()`, graceful denied/undetermined messaging,
   "Start →" sets `has_onboarded=1` + seeds catalog, then `router.replace('/wardrobe')`.
- `src/store/onboarding.ts` — `useOnboarding(): boolean | null`: `null` while loading,
     then reads `has_onboarded`. `null` → parent shows a loading spinner (index gate).
- `app/index.tsx` — routing gate: unboarded → `/onboarding` (Redirect); onboarded → `/wardrobe`.
   Permission outcome handling: granted/denied/undetermined + `canAskAgain` all rendered
    without crashing.

### Findings
- **D7 — permission APIs:** camera via `expo-camera` (`Camera.requestCameraPermissionsAsync`),
    photo import via `expo-image-picker` (`requestCameraPermissionsAsync` / media library).
- **SDK 57 quirk:** permission status uses the `PermissionStatus` enum
    (`'granted'`/`'denied'`/`'undetermined'` + `canAskAgain`), not a `granted: boolean`
    field as in older docs. Handled in both `onboarding.tsx` and `wardrobe.tsx`.
- i18n structure only (no catalog) — strings are inline; a proper i18n wiring is M3-3.
