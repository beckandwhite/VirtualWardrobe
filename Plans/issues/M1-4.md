# M1-4 · Bundled store.json catalog + ingester

Milestone: M1 · Labels: feat, M1

## Description
Provide a built-in catalog so users have something to try instantly, fully offline.

## Tasks
- Author a small curated `assets/store.json` (e.g. 20 items) + bundled images.
- On first run, ingest catalog entries into the store as `StoreItem` rows (idempotent).
- Surface them in the catalog/wardrobe with a "Try on" action.

## Acceptance criteria
- [ ] Catalog items appear without any network.
- [ ] A catalog item can be "added" (copied) into the user's wardrobe.
- [ ] Re-running the ingester does not duplicate rows.

## Notes
Stays local by default (ADR-004). A remote catalog is a future enhancement, not MVP.
