# M1-3 · Gallery grid + filter/search

Milestone: M1 · Labels: feat, ux, M1

## Description
The wardrobe browse experience: a grid plus filter by category/color and text search over tags.

## Tasks
- Grid UI of wardrobe items with thumbnails.
- Filters: category (top/bottom/dress/outerwear/shoes/other) and color.
- Text search across name + tags.
- Long-press / tap → detail (M1-2) and a quick "Try on" entry that deep-links to the studio.

## Acceptance criteria
- [ ] Filter returns the correct subset; multiple filters AND together.
- [ ] Search matches name + tags (case-insensitive).
- [ ] Empty state is handled.
- [ ] "Try on" deep-links to the studio with that item preselected.

## Deps
Depends on M1-2.
