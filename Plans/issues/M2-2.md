# M2-2 · Auto-scaled garment box from keypoints + manual fine-tune

Milestone: M2 · Labels: feat, ux, M2

## Description
Turn pose into a believable drape: auto-place the garment, then let the user perfect it.

## Tasks
- Use `computeGarmentBox` to derive initial position/scale/rotation from keypoints + type.
- Manual controls (Reanimated): position (drag), scale (pinch/slider), rotation, opacity.
- Live composite of garment over the body photo in the studio.
- Serialize the final transform into the `TryOn` row.

## Acceptance criteria
- [ ] For a given pose, the garment starts roughly correct (no full manual nudge).
- [ ] All four manual controls adjust the garment smoothly on web + simulator.
- [ ] Final transform is reproducible / serializable.
- [ ] No jank: transforms run on the UI/reanimated thread.

## Deps
Depends on M0-2, M2-1 (web). Works with manual fallback too (M2-4).
