# M2-2 · Auto-scaled garment box from keypoints + manual fine-tune

Milestone: M2 · Labels: feat, ux, M2

## Description
Turn pose into a believable drape in two stages: **auto-place** (derive an initial
position/scale/rotation from keypoints + garment type via `computeGarmentBox`, M0-2), then
**let the user perfect it** with manual controls. This is where ADR-001 lands hard — the manual
position/scale/rotation/opacity layer is a **first-class feature**, not an afterthought, because
the overlay is 2D compositing, not a true 3D fit.

All interactive transforms run through `react-native-reanimated` on the UI thread so dragging and
pinching stay smooth (60fps-ish) on the studio screen. The final transform is serialized into the
`TryOn` row so a look is reproducible and reopenable (M3-2).

## Tasks
- `src/composer/autoBox.ts` — call `computeGarmentBox(keypoints, garmentType)` to get the initial
  `{x, y, scale, rotation, opacity}`; clamp/normalize to the studio's coordinate space.
- The studio screen (**`app/studio.tsx`, kept flat per D19.4 — not `app/studio/StudioScreen.tsx`**)
 — a fixed body-photo layer with an overlaid garment image driven by a Reanimated `useAnimatedStyle`
 from a `useSharedValue` transform. M2-2 re-enables `react-native-reanimated/plugin` in
  `babel.config.js` and re-verifies web + native builds (D19.7).
- Manual controls (Reanimated gestures): position via a `PanGestureHandler`-style `PanResponder`/
  `gestureHandler`, scale via a pinch gesture **and** a slider (for precision + accessibility),
  rotation via a dial/slider, opacity via a slider. Provide a "Reset" button back to the
  auto-box.
- A faint **live composite**: garment image blended over the body photo at the current transform;
  keep the keypoint overlay (from M2-1) toggleable.
- `serializeTransform(t)` → a stable JSON object stored on the `TryOn.transform` field (M0-3) so
  the exact look can be reconstructed later.

## Acceptance criteria
- [x] For a given pose + garment type, the garment starts **roughly correct** (usable with only
      small nudges, not a full manual placement). — `autoTransformFor(computeGarmentBox(...))`
      pre-places; sliders/drag only nudge.
- [x] All four manual controls (position, scale, rotation, opacity) adjust the garment smoothly on
      web **and** simulator; no main-thread jank. — code-complete on the UI thread via Reanimated
       `useSharedValue`/`useAnimatedStyle` + `withTiming`; smoothness/jank not exercised in-sandbox
        (no simulator/browser — tracked in M3-5).
- [x] "Reset" returns the garment to the auto-derived box. — `applyTransform(autoRef.current)`.
- [x] The final transform serializes deterministically (same inputs → same JSON) and round-trips
      through the `TryOn` row. — `serializeTransform`/`deserializeTransform` round-trip tested in
       `tests/composer/transform.test.ts`; `TryOn.transform` stores the JSON.
- [x] Works with the manual fallback too (transform type is identical when keypoints are null — M2-4).
       `autoTransformFor([])` returns the same `Transform` type as the auto path.
- [x] Transform math lives in `src/composer/` (pure) and has a Jest test for the serialize step.
       — `src/composer/transform.ts` (`clampTransform`/`autoTransformFor`) + `tests/composer/`.

## Status: BUILT (2026-09-20)
Gate-green (tsc + eslint + jest). UI-thread smoothness not exercised in-sandbox (M3-5).

Depends on M0-2 (interfaces + `computeGarmentBox`), M2-1 (web keypoints). Works with the manual

## Out of scope
- Physics-based cloth drape / real 3D — explicitly deferred (ADR-001, non-goal in M0).
- Live-camera AR try-on — deferred.
